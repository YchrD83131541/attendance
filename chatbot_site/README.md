# アクロポートガイド チャットボット

アクロポート フィットネスクラブの FAQ チャットボットサイトを配信するローカル Web サーバーです。

## ファイル構成

```
c:\python\
├── ai_chatbot.py        ← サーバー起動スクリプト
└── chatbot_site\
    ├── index.html       ← チャットボット画面
    ├── app.js           ← チャットボットのロジック（FAQ・返答定義）
    ├── styles.css       ← デザイン（ブルーテーマ）
    └── images\          ← 料金表・キャンペーン・背景画像など
```

## 起動方法

```bash
python ai_chatbot.py
```

起動後、ブラウザで以下にアクセスしてください。

```
http://127.0.0.1:8000
```

ポートを変更したい場合：

```bash
python ai_chatbot.py --port 8080
```

## 機能

- **サービス切り替え**: 大人のフィットネス / 子供のスイミングをラジオボタンで選択
- **FAQ ボタン**: サービスに応じたよくある質問ボタンを表示
- **フリーテキスト入力**: 質問を直接入力して回答を取得
- **画像表示**: 料金表・キャンペーン・バス案内などの画像を回答に添付
- **背景切り替え**: サービス選択に応じて背景画像が切り替わる

## 返答内容の変更方法

`app.js` を編集します。

| 変更内容 | 編集箇所 |
|----------|----------|
| 返答テキスト | `getReply()` 関数内の `return` 文 |
| FAQ ボタンの項目 | `FAQ_BUTTONS` オブジェクト |
| ボタン押下時の表示画像 | `REPLY_IMAGES` オブジェクト |

## 注意事項

- サーバーを停止するには `Ctrl+C` を押してください
- ポートが使用中の場合は `--port` オプションで別のポート番号を指定してください
